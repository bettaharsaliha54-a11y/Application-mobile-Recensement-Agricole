# 🌾 مشروع الإحصاء الفلاحي (Agricultural Census Application)

تطبيق متكامل لإدارة عملية الإحصاء الفلاحي، مصمم لتسهيل جمع البيانات الميدانية بدقة وكفاءة عالية.

## 🎨 الهوية البصرية (Design System)
يتميز التطبيق بتصميم احترافي يعكس طبيعة القطاع الفلاحي:
- **الألوان الأساسية:** يعتمد التطبيق على **تدرجات اللون الأخضر** (Forest Green, Emerald, Mint) ليعطي شعوراً بالثقة والطبيعة.
- **التصميم:** واجهات عصرية، بسيطة، وسهلة الاستخدام للمحققين الميدانيين.

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Frontend:** [Flutter](https://flutter.dev) (Dart) - تطبيق محمول يعمل على Android.
- **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python) - نظام إدارة البيانات والمصادقة.
- **Database:** 
  - **SQLite:** لتخزين البيانات محلياً (Offline-first).
  - **PostgreSQL:** لقاعدة البيانات المركزية.

## 📊 المميزات الرئيسية
- 🌍 **ثنائي اللغة:** دعم كامل للغتين العربية والفرنسية.
- 📶 **العمل بدون إنترنت:** إمكانية جمع البيانات وحفظها محلياً ثم مزامنتها لاحقاً.
- 📋 **استبيانات شاملة:** إدارة 14 قسماً مختلفاً من الاستبيانات (المستغل، المستغلة، المحاصيل، المواشي، إلخ).
- 🔐 **أمان البيانات:** نظام مصادقة محكم لحماية البيانات الحساسة.

## 📂 هيكلة المشروع
```text
├── backend/        # كود الخادم (Python/FastAPI)
├── frontend/       # كود تطبيق المحمول (Flutter)
└── README.md       # وثائق المشروع
```

## 🛠️ كيف تشغيل المشروع
1. **للخادم (Backend):** قم بتثبيت المتطلبات من `requirements.txt` ثم تشغيل `main.py`.
2. **للتطبيق (Frontend):** تأكد من تثبيت Flutter، ثم قم بتشغيل `flutter run`.
